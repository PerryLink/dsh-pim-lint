## Instalación

Instalar y verificar:

```sh
dsh plugin --profile <profile> add dsh-pim-lint
dsh --profile <profile> --dump-config | grep dsh-pim-lint
```

Desinstalar:

```sh
dsh plugin --profile <profile> remove dsh-pim-lint
```

## Qué hace

Lint de catálogo PIM: campos obligatorios, SKU duplicado, dígito GTIN y precio. Se ejecuta localmente en DeepSeek Harness. La tabla siguiente es la superficie exacta de herramientas; los ejemplos usan la interfaz real.

La entrada y la salida permanecen locales; no se sube nada.

## Herramientas

Los nombres y descripciones de herramientas se mantienen en inglés para coincidir con la salida runtime.

| Herramienta | Propósito (en inglés) | Riesgo |
|---|---|---|
| `pim.validate` | Validate `sku,title,gtin,price` CSV rows and return issues | R0 |
| `pim.gtin_check` | Check GTIN-8/12/13/14 check digits | R0 |
